# Learning Python

My code from the CodeWithHarry [Ultimate Python Course](https://youtu.be/UrsmFxEIp5k).
Nothing here is a library or a tool. It is practice work.

## Why

I have worked in JavaScript and TypeScript for years. I have shipped Python
too, but the AI wrote it. I read that code and understood most of it, and I
still could not sit with an empty file and write Python on my own.

So I am doing the course properly. Watch a chapter, type it out, do the
problems, move on.

## The one rule

No AI writes the Python in this repo. Not a solution, not a snippet, not a one
character fix.

Hints are allowed. Code is not. If I get stuck I sit with it, or I go back to
the video.

That is what [AGENTS.md](./AGENTS.md) is for. It is not here to help the AI
write code. It is here to stop it.

## Folders

- `Chapter N` is the code I write along with that chapter
- `Chapter N - PS` is the problem set for it
- `Project 1`, `Project 2`, `Mega Project 1 - Jarvis`,
  `Mega Project 2 - AI AutoReply Bot` are the four projects

Every folder has a README with its topics. Run any file with
`python3 filename.py`.
